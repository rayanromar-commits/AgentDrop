# Retired clip-ranking lists

Lists moved out of `clip_ranking_data/` because they cannot be built honestly
from stock footage. Kept (not deleted) so they can come back if a better
footage source (Pixabay key, a paid licensor) makes them sourceable.

- `ranking_deadliest_predators_that_hunt_humans.json`,
  `ranking_most_dangerous_sharks.json` — both put **Great White** at #1, the
  payoff slot, which is never substituted. Pexels has no real great-white
  footage: on 2026-09-17 two renders captioned a shallow-reef shark silhouette
  and then an aquarium **sand tiger** as "Great White Shark".
